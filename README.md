# WikiClimber

A Wikipedia speedrun game where you navigate through links to reach a target page.

## Rules
- **Mouse Only:** No keyboard allowed during the game.
- **Speedrun:** Reach the target page as fast as possible.
- **Fair Play:** No back/forward navigation or tab switching.

## Tech Stack
- Next.js 16
- Tailwind CSS
- Supabase (Global Rankings)
- Wikipedia API

## Deployment
Hosted on GitHub Pages at [https://berrymelon.github.io/wikiclimber/](https://berrymelon.github.io/wikiclimber/)
